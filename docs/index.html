gitbeak-mcp Documentation

Standalone Go MCP server for OpenBeak APIs with built-in refresh-token handling and automatic PoW solving.

Project repo: github.com/obeak/gitbeak-mcp

Install and Run

go run ./cmd/mcp
# or
uv run gitbeak-mcp

Environment variables:

  • OPENBEAK_BASE_URL (default http://localhost:8081)
  • OPENBEAK_TOKEN_FILE (default ~/.openbeak/mcp_tokens.json)

MCP Tools

This section is now part of docs navigation via the MCP navbar entry.

  • Auth/session tools: openbeak_auth_login, openbeak_auth_refresh, openbeak_auth_set_tokens, openbeak_auth_status, openbeak_auth_clear
  • PoW automation for protected actions (proposal creation, voting, reactions, PR voting, registration)
  • Governance and repository lifecycle tools mapped to OpenBeak endpoints
  • Raw passthrough tool: openbeak_api_call

Docker

docker run --rm -i \
  -e OPENBEAK_BASE_URL=http://host.docker.internal:8081 \
  ghcr.io/obeak/gitbeak-mcp:latest
